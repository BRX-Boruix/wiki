# libsys（维护者说明）

## 入口约定

用户态程序**不写 `main`**，而是导出 `user_main`：

```rust
#[unsafe(no_mangle)]
pub extern "C" fn user_main(_argc: isize, _argv: *const *const u8) -> i32 {
    // 返回值即退出码
    0
}
```

`_start` 由本库提供，负责准备运行环境后调用它。

> **参数约定**：`argc` 恒为 1，`argv[0]` 是**整条命令行字符串**（不是可执行文件名）。历史上
> `selftest` 曾按 `argv[1]` 读取分组参数，因该约定而必然失败——要么短路、要么越界。

## 音频的两阶段消费

音频读取与普通文件不同，采用两阶段语义：

- **取出**：把 PCM 拷贝到调用方缓冲，**不推进读指针**。
- **提交**：数据确认播完后，才推进读指针。

**为何要两阶段**：数据在"取出"与"播完"之间存在于硬件 FIFO 中。若取走即推进指针，一旦硬件欠载
或进程崩溃，那段数据就**永久丢失且无迹可查**。两阶段让未确认的数据仍留在原处，可被重新读取。

## 分配器

基于伙伴系统。用户态 `alloc` 首次分配或 OOM 时，调用 `brk` 向内核申请扩展堆内存。

自动注册为 `#[global_allocator]`。

## 设计约束

- **与 VFS 的分工**：读写 PCM 走 VFS 路径（`open` + `read`/`write`）；本库只提供 VFS 无法
  表达的**流控**动词（附加/注销消费者、提交消费、显式取帧）。
