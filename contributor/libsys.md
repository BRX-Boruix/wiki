# libsys

用户态系统调用库。把内核提供的系统调用封装为 Rust 函数。

## 入口约定

用户态程序不定义 `main`，而是导出 `user_main`：

```rust
#[unsafe(no_mangle)]
pub extern "C" fn user_main(_argc: isize, _argv: *const *const u8) -> i32 {
    // 返回值即退出码
    0
}
```

`_start` 由本库提供，负责准备运行环境后调用它。

**参数约定**：`argc` 恒为 1，`argv[0]` 是整条命令行字符串，不是可执行文件名。按 `argv[1]` 读取
参数会越界，或在长度为 1 时短路。

## 分配器

基于伙伴系统，自动注册为 `#[global_allocator]`。用户态 `alloc` 首次分配或内存不足时，调用 `brk`
向内核申请扩展堆内存。

## 音频的两阶段消费

音频读取采用两阶段语义：

- **取出**：把 PCM 拷贝到调用方缓冲，不推进读指针。
- **提交**：数据确认播完后，才推进读指针。

数据在取出与播完之间存在于硬件 FIFO 中。若取出即推进指针，硬件欠载或进程崩溃时那段数据将
永久丢失且无迹可查。两阶段使未确认的数据仍留在原处，可被重新读取。

## 与 VFS 的分工

读写 PCM 走 VFS 路径（`open` 加 `read`/`write`）。本库只提供 VFS 无法表达的流控动词：附加与
注销消费者、提交消费、显式取帧。
