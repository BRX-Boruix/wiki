# pwde2e

POSIX 账户查询的用户态端到端验收。README 面向使用者；本文件记录验收设计。

## 为什么必须是独立进程

同类检查在库的自测中以进程内形式存在。进程内检查验证不了「任意用户程序经 libc 链接、穿越
syscall 边界」这条完整链路——那需要真实的 exec、真实的动态链接入口、真实的 errno 上抛。
本程序由 selftest 的 quick 组以真实 exec 路径拉起，与进程内检查互补，不互相替代。

## 失败项编号即退出码

返回首个失败项的编号：一眼定位断在链路哪一环，不需要解析输出。编号顺序即链路顺序：表缺失
判定、表写入、按名查询、字段核对、按 id 往返。

## 账户表的处理

检查需要一张受控的表：程序自己写 `/config/users.json`，三个账户。carol 不写 gid 字段，
验证缺 gid 的条目回退取 uid；按 id 反查用 bob（1001），与按名查询的 alice 不是同一条，
往返不是复读。表写入失败按装配错误处理，与判定失败区分退出码。
